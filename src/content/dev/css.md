# CSS styles

Anders har helt siden han var liten gutt elsket CSS. Da jeg luftet idéen "Blogg på utveksling" var noe av det første han ønsket seg å kunne lage masse interessant webdesign! Jeg har derfor implementert en magisk "CSS-velger" som bytter mellom forskjellige CSS stiler. Per nå bytter den kun mellom **"vanlig stygg"** og **"vanlig stygg med grå bakgrunn og arial font"**.

I fremtiden er håpet vårt at vi skal kunne lage egne morsomme stiler for som vi kan teste ut på dere. Innen siden vår går live så bør vi ha på plass kommentarfelt så vi kan se hva dere leser tenker om designvalgene våre.
